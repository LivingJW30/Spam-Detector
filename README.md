# Spam-Detector
This repository documents the steps I took to build my first ML model using the Spambase dataset from UC Irvine.

Included are notes to document my understanding of the topic. 

### Project Directory
- ```spam_detector.joblib``` - the packaged ML model.
- ```test.ipynb``` - The documentation and code used to train the model.
- ```emails_scored.json``` - a set of example emails along with their features and labels.
- ```user.py``` - a Python script to load the model and test it against the aforementioned example emails.
